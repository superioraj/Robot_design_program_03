# ROBOT DEVELOPMENT REPORT #1

최종 선정된 로봇 아이디어를 바탕으로 개발 보고서의 01~04 단계만 작성하는 정적 웹 프로그램입니다.

## 포함된 활동
1. 기본 정보와 최종 한 줄 아이디어
2. 문제와 개발 목표
3. 마이크로비트·링비트·서보모터 1개의 작동 원리
4. 알고리즘

05 설계와 제작 과정, 06 시험과 개선, 07 개발 결과와 성찰은 이 프로그램에 포함하지 않았습니다.

## 주요 기능
- 앞 활동의 아이디어 선정 매트릭스 JSON 불러오기
- 알고리즘 기본 4단계, 최소 2단계, 최대 8단계
- 알고리즘 단계 추가·삭제 및 번호 자동 정렬
- 브라우저 임시 저장
- 01~04 보고서 JSON 백업
- 흰 배경·검정 글자의 A4 PDF 출력
- DOS/CRT 입력 화면, 반응형 UI, 키보드 단축키

## 단축키
- F1: 미리보기
- F2: 전체 초기화
- F3: 임시 저장
- F4: PDF 출력/저장
- F6: JSON 백업

## 실행 및 배포
`index.html`을 최신 브라우저에서 열면 바로 실행됩니다. GitHub Pages에서는 `index.html`과 `README.md`를 저장소 루트에 올리고 Settings > Pages에서 main 브랜치 root를 배포 대상으로 지정합니다.

## 개인정보
입력 데이터와 JSON 파일은 브라우저 내부에서만 처리되며 외부 서버로 전송되지 않습니다.
